## Dataset

The `True.csv` dataset is not included in this repository due to its large file size.

You can download the dataset from Kaggle:

[Download the True.csv Dataset](https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset?select=True.csv)

After downloading the dataset, place `True.csv` in the project directory before running the notebook.
